01 - CCT-YOLO

Transformer-Enhanced Real-Time Object Detection

Deep Learning - Computer Vision - Transformers - YOLO

CCT-YOLO is a lightweight object detection system that explores the use of a Compact Convolutional Transformer (CCT) as an alternative backbone for YOLO-based object detection.

The project was designed to investigate whether transformer-based representations could be integrated into an object detection architecture while substantially reducing model complexity.

What I Built

  • Designed a custom CCT backbone using convolutional tokenization and transformer encoder layers.
  • Integrated the CCT backbone with a YOLO detection head.
  • Built the complete machine-learning pipeline from dataset processing through inference.
  • Trained and evaluated the model using the Pascal VOC 2012 dataset.
  • Implemented loss calculation, evaluation, inference, and detection visualization.
  • Analyzed model size, parameter count, detection performance, and per-class results.

Results

5.22 MBFinal model size
1.37MModel parameters
21.88%mAP@0.5

02 - ALMP

Adaptive Learning-Based Mutation Prioritization

Machine Learning - Software Testing - Software Engineering

ALMP is a machine-learning framework designed to improve the efficiency of mutation testing by intelligently prioritizing mutants according to their predicted testing value.

Instead of treating every generated mutant equally, the system explores how machine learning can identify mutants that are more valuable for testing.

What I Built

  • Developed an ML-based mutant prioritization approach.
  • Analyzed mutant characteristics influencing prioritization decisions.
  • Built a benchmarking workflow against a baseline/random selection strategy.
  • Evaluated mutation score, token usage, and cost efficiency.
  • Applied data analysis and visualization to interpret results.
  • Implemented the framework in Python.

Results

75%Mutation score
25%Baseline mutation score

The benchmark demonstrated the potential for adaptive ML-based prioritization to improve testing effectiveness under similar processing constraints.
