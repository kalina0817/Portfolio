# Portfolio Repository

This repository contains a personal portfolio with one primary implementation and one archived implementation.

## Primary Implementation (Maintained)

- Static site: index.html
- Supporting files: style.css, script.js, assets/

## Archived Implementation (Reference)

- React app: kalkidan-portfolio/
- Status: archived and not the primary maintained version

## Local Development

1. Open index.html in a browser for quick preview.
2. Edit content in index.html.
3. Edit styles in style.css.
4. Edit client behavior in script.js.

## Deployment

1. Commit changes to the repository.
2. Push to the default branch used by GitHub Pages.
3. GitHub Pages serves the root static files using this path:
   https://kalina0817.github.io/Portfolio/
