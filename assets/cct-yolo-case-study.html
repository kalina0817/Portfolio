CCT-YOLO Case Study

Aug 2025 - Dec 2025

CCT-YOLO explores whether a compact transformer-based backbone can reduce object-detection model complexity while preserving practical performance.

Problem Statement

Real-time object detection often requires a tradeoff between model efficiency and detection quality. This work investigates a lightweight architecture path for deployment-oriented use cases.

Method

  • Replaced a conventional YOLO backbone with a Compact Convolutional Transformer backbone.
  • Integrated the custom backbone with a YOLO detection head.
  • Built a full training and evaluation pipeline in Python and PyTorch.

Experimental Setup

  • Dataset: Pascal VOC 2012 (20 classes)
  • Training duration: 25 epochs
  • Evaluation metric: mAP@0.5
  • Artifacts: architecture diagram, detection outputs, and reproducible code in repository

Key Takeaway

The project demonstrates strong compactness gains and a practical path for efficiency-focused detector research, with clear opportunities to improve mAP through further training and optimization.
